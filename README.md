# TFG_Informatica

## Estrategias

 - MV (mean - variance)
 - SRO (sharpe ration optimization) -> Todos los algoritmos propuestos optimizan primero el ratio de sharpe
 - GMR (global maximum return)  -> maxReturn.py
 - GMV (global minimum variance)  -> minRisk.py
 - SSD (second-order stochastic dominance)
 - MD (maximum diversification)
 - EW (equally weighted) -> naive.py
 - EWRC (equally weighted risk contribution)

 - Maximizar sostenibilidad


## Librerias usadas

Deap: libreria para el diseño de algoritmos geneticos y evolutivos
cvxpy: libreria para resolver problemas de optimizacion convexa
